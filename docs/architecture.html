The one design rule: judgement goes to an agent, arithmetic goes to a tool. Whether “Kung Pao Chicken” is a temperature-controlled food is a judgement about a free-text menu name. How long it then stays safe is arithmetic against a published rule — and the Safety Agent is instructed never to state a deadline it did not get back from a tool.
